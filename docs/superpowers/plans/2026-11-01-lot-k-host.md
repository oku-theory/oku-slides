## Task 1: t-1377 — quitting runs the close guards

Today `quit`, the menu Quit, a native close of the last window, a `CloseWindow` request on the last window and
install-and-restart call `state::shutdown` (or `settle`) without the pages: a widget write the editor deferred
(typed, not yet sent) and the detached agent's debounced draft are lost.

- [ ] Pure `QuitBarrier` in `oku-slides-session` (`quit_barrier.rs`, tested by `just test`, as the src-tauri
  Testing rule asks): the windows waited for, answers keyed by label (unknown, duplicate or late answers
  ignored; none waited for: done at once), a second request joining the first, exactly one release.
- [ ] Host `src-tauri/src/quit.rs`: a guarded exit emits `quit-requested { ms: QUIT_GUARD_MS }` to every
  window (workspace windows and the agent window), waits on a tokio `Notify` with `timeout(QUIT_WAIT)` (guard
  bound plus 1 s), never on the main thread, then runs the exit. `closing` is set only by `settle` after the
  wait, so the guards' `request`/`workspace` writes are accepted meanwhile. `quit_ready` takes the answering
  window from the injected `WebviewWindow`, never a payload.
- [ ] Routed: `commands::quit`, the menu Quit, `close_requested` on the last window, `commands::workspace`'s
  `is_last_window`, and `install_update` (barrier, then its settle and restart). Left direct, documented in
  `main.rs`: `windows::sync` on an empty view (every tab closed through its close flow, guards run) and
  `RunEvent::Exit` (Dock, logout: tao's `applicationWillTerminate`, webviews going away, cannot be waited for).
- [ ] UI: `closeGuards.ts` exports `runAllCloseGuards(ms)` over the whole registry (unmounted entries
  included: a tab dragged away keeps its pending write here); `Workspace` answers `quit-requested` with it
  then `quit_ready` (in `finally`; a second request joins the running one); `AgentWindow` flushes its draft
  then answers. The comment "Quit runs no guard" goes. Render/unit tests: guard pending → answer after it;
  rejected or stalled guard → still answers.
- [ ] Docs: `src-tauri/AGENTS.md` exit rule, `ui/AGENTS.md` close rule ("except quit" → quit runs every guard,
  bounded, and asks nothing), `main.rs` exit-path doc. e2e cannot reach a Tauri quit: the app is checked by hand.
