# Fil de l'agent tout en A2UI — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Le fil de l'agent devient une suite de surfaces A2UI construites par l'hôte (un tour = consigne, timeline, reçu), avec un dock pour les surfaces vivantes, un catalogue v3 et plus aucun style post-it.

**Architecture:** Les évènements ACP passent par un réducteur Rust de tours (`oku-slides-agent/src/turns.rs`) qui fabrique la surface `turn-N` (constructeurs purs dans `oku-slides-session/src/agent/turn_view.rs`) et l'émet par le `SurfaceHub`, comme toute surface d'outil ; la progression part en `McpEvent::SurfacePatch` que `SurfaceView` applique sans reconstruire. L'agent conclut par l'outil `report` (reçu) et dispose de `render` (composition libre validée en Rust). L'interface ne garde que l'état de l'agent et range les surfaces par tour ou dans le dock.

**Tech Stack:** Rust (serde, schemars, insta, speculoos, rstest), A2UI v0.9 (`@a2ui/react` 0.11.1, `@a2ui/web_core` 0.11.0, zod 3), React 19, Bun test + happy-dom, Fluent.

**Spec:** `docs/superpowers/specs/2026-10-03-agent-a2ui-design.md` (tâche t-416).

## Global Constraints

- Identifiant de catalogue : `urn:oku-slides:a2ui:catalog:v3` (Rust `CATALOG_ID` et TS `CATALOG_ID` identiques ; pas de v2 conservée).
- `Prompt` et `Timeline` : réservés à l'hôte ; `render` les refuse.
- `report` : `facts` 1 à 4, `actions` 0 à 4 ; `render` : 40 composants au plus, profondeur 6 au plus ; seule action permise dans `render` : `suggest {prompt}`.
- Tours gardés par onglet : 50 (`KEPT_TURNS`) ; surfaces figées par tour : 8 (`STATIC_PER_TURN`).
- Textes de l'agent (`agent/bounds.rs`) : titre, fait, badge 120 caractères (`TEXT_MAX` = `NOTE_CHARS`), libellé 60, explication et texte 4000, consigne 2000 ; ni contrôle bidirectionnel ni caractère invisible. `render` : 64 Kio par appel, arbre strict, valeurs littérales seulement (ni `{path}` ni `data`), ni style `primary`/`danger`, ni `Receipt`, `SlideThumb`, `Prompt`, `Timeline` ; seul un bouton porte une action, `suggest`, qui envoie son libellé. Hors d'un tour ouvert, `render` et `report` sont refusés.
- Dock : au plus deux surfaces (une question, un jeu de réglages), hauteur ≤ 45 % du panneau.
- Typographie des cartes : corps 400 14/20, notes 400 12/16 `--ink-muted`, titres 600 14/20.
- Aucun style post-it ne reste : ni jeton `--postit*`/`--app-postit`, ni classe `.postit*`, ni `--tilt`.
- Textes visibles : Fluent, dans les 20 langues de `crates/oku-slides-i18n/src/locales/*` (le test de parité d'`oku-slides-i18n` doit passer).
- Commits : Conventional Commits, scope, ` (t-<sous-tâche>)` ; pas de ligne `Co-Authored-By` ; `git add` dans une commande séparée du `git commit`.
- Fichiers : 500 lignes visées, 1000 au plus.
- Commandes : Rust `cargo nextest run -p <crate>` ; UI `cd ui && bun test` (rendus : `bun test .render.test.`) ; types `cd ui && bun run typecheck` ; fixture `OKU_UPDATE_FIXTURES=1 cargo nextest run -p oku-slides-session every_form_matches_the_ui_fixture`.

```rust
            ComponentKind::Prompt { .. }

impl ComponentKind {
    /// Le même composant, en lecture seule ; `None` pour un bouton (sans action, il n'a plus de sens).

        Some(match self {
            Self::Button { .. } => return None,
            Self::TextField { label, value, .. } => Self::TextField { label, value, action: None },
            Self::Stepper { label, value, min, max, .. } => Self::Stepper { label, value, min, max, action: None },
```

```tsx
// Composants du fil de l'agent (catalogue v3) : consigne, timeline, reçu,
// détail repliable, badge, Markdown. Hors de catalog.tsx : un concept par fichier.

import { useState } from "react";
import { z } from "zod";
import { createComponentImplementation } from "@a2ui/react/v0_9";
import { CommonSchemas } from "@a2ui/web_core/v0_9";
import { Markdown as MarkdownView } from "../agent/Markdown";
import { Hex, ToneSchema, toneClass } from "./schemas";
import { Toggle } from "./Toggle";
const Step = z.object({
  label: z.string(),
  status: z.enum(["pending", "in_progress", "completed", "failed"]),
  count: z.number().int().optional(),
}).strict();

const PromptApi = { name: "Prompt", schema: z.object({ text: CommonSchemas.DynamicString }).strict() };
const TimelineApi = {
  name: "Timeline",
  schema: z.object({
    steps: z.union([z.array(Step), z.object({ path: z.string() }).strict()]),
    collapsed: CommonSchemas.DynamicBoolean,
    summary: CommonSchemas.DynamicString,
  }).strict(),
};
const ReceiptApi = {
  name: "Receipt",
  schema: z.object({
    title: CommonSchemas.DynamicString,
    facts: z.array(z.string()).readonly(),
    thumb: z.string().optional(),
    swatch: Hex.optional(),
  }).strict(),
};
const DisclosureApi = {
  name: "Disclosure",
  schema: z.object({ summary: CommonSchemas.DynamicString, child: CommonSchemas.ComponentId }).strict(),
};
const BadgeApi = { name: "Badge", schema: z.object({ text: CommonSchemas.DynamicString, tone: ToneSchema.optional() }).strict() };
const MarkdownApi = { name: "Markdown", schema: z.object({ text: CommonSchemas.DynamicString }).strict() };

/** Marque d'une étape selon son statut. */
const MARK: Record<z.infer<typeof Step>["status"], string> = { pending: "○", in_progress: "◌", completed: "✓", failed: "✕" };

/** La consigne de l'utilisateur. */
export const Prompt = createComponentImplementation(PromptApi, ({ props }) => (
  <p className="a2ui-prompt">{props.text}</p>
));

/** La progression d'un tour ; repliée, une ligne qui se déplie au clic. */
export const Timeline = createComponentImplementation(TimelineApi, ({ props }) => {
  const [open, setOpen] = useState(false);
  // Une valeur liée par chemin n'est pas validée par zod : on ne garde que des étapes bien formées.
  const steps = (Array.isArray(props.steps) ? props.steps : []).filter((x): x is z.infer<typeof Step> => Step.safeParse(x).success);
  const shown = !props.collapsed || open;
  return (
    <div className="a2ui-timeline">
      {props.collapsed && (
        <Toggle open={open} onToggle={() => setOpen(!open)} className="a2ui-timeline-summary">{props.summary}</Toggle>
      )}
      {shown && (
        <ol className="a2ui-steps">
          {steps.map((s, i) => (
            <li key={i} className={`a2ui-step ${s.status}`} /* `status` vient de l'énumération de `Step` : une valeur sûre */>
              <span aria-hidden="true">{MARK[s.status]}</span>
              <span className="a2ui-step-label">{s.label}</span>
              {s.count !== undefined && <span className="a2ui-badge">{s.count}</span>}
            </li>
          ))}
        </ol>
      )}
    </div>
  );
});

/** La conclusion d'un tour. */
export const Receipt = createComponentImplementation(ReceiptApi, ({ props }) => (
  <div className="a2ui-card tone-accent a2ui-receipt">
    {props.thumb && <img className="a2ui-receipt-thumb" alt="" src={`data:image/svg+xml;utf8,${encodeURIComponent(props.thumb)}`} />}
    {!props.thumb && props.swatch && <span className="a2ui-swatch" style={{ background: props.swatch }} aria-hidden="true" />}
    <div className="a2ui-receipt-text">
      <span className="a2ui-title">{props.title}</span>
      {props.facts.length > 0 && <span className="a2ui-hint">{props.facts.join(" · ")}</span>}
    </div>
  </div>
));

/** Un enfant replié derrière une ligne. */
export const Disclosure = createComponentImplementation(DisclosureApi, ({ props, buildChild }) => {
  const [open, setOpen] = useState(false);
  return (
    <div className="a2ui-disclosure">
      <Toggle open={open} onToggle={() => setOpen(!open)} className="a2ui-hint">{props.summary}</Toggle>
      {open && buildChild(props.child)}
    </div>
  );
});

/** Un compteur ou un statut. */
export const Badge = createComponentImplementation(BadgeApi, ({ props }) => (
  <span className={`a2ui-badge${toneClass(props.tone)}`}>{props.text}</span>
));

/** Du Markdown, sans HTML brut. */
export const Markdown = createComponentImplementation(MarkdownApi, ({ props }) => (
  <div className="a2ui-md md"><MarkdownView text={props.text ?? ""} /></div>
));
```

```rust
    /// Applique des messages de mise à jour à la copie de l'hôte (resynchronisation).
    ///
    /// Un modèle racine remplace celui de la surface (et rend caducs les
    /// chemins écrits avant lui) ; un chemin `/clé` (JSON Pointer, `~0`/`~1`
    /// décodés) y écrit sa valeur, ou retire la clé sans valeur ; tout autre
    /// message est ajouté tel quel.
    pub fn apply_patch(&mut self, messages: &[ServerMessage]) {
        for m in messages {
            let ServerBody::UpdateDataModel(patch) = &m.body else {
                self.messages.push(m.clone());
                continue;
            };
            match patch.path.as_deref() {
                None => {
                    // Les écritures par chemin antérieures sont remplacées par la nouvelle racine.
                    self.messages.retain(|x| !matches!(&x.body, ServerBody::UpdateDataModel(u) if u.path.is_some()));
                    match self.root_model() {
                        Some(root) => root.value.clone_from(&patch.value),
                        None => self.messages.push(m.clone()),
                    }
                }
                Some(path) => {
                    if let Some(key) = path.strip_prefix('/')
                        && !key.contains('/')
                        && let Some(root) = self.root_model()
                        && let Some(Value::Object(map)) = &mut root.value
                    {
                        let key = key.replace("~1", "/").replace("~0", "~");
                        match &patch.value {
                            Some(v) => map.insert(key, v.clone()),
                            None => map.remove(&key),
                        };
                    } else {
                        self.messages.push(m.clone());
                    }
                }
            }
        }
    }

    /// Le message qui porte le modèle de données racine.
    fn root_model(&mut self) -> Option<&mut UpdateDataModel> {
        self.messages.iter_mut().find_map(|x| match &mut x.body {
            ServerBody::UpdateDataModel(u) if u.path.is_none() => Some(u),
            _ => None,
        })
    }
```

`buildSurface` rend aussi son processeur, libère la surface partiellement construite en cas d'erreur, et sert à l'effet (plus seulement aux tests). `MessageProcessor` exige son argument de type : `import type { A2uiClientAction, A2uiMessage, ComponentApi, SurfaceModel } from "@a2ui/web_core/v0_9";` (vérifié avec tsc).

```tsx
/** Une surface construite (et son processeur, pour la prolonger), ou l'erreur de validation de ses messages. */
export interface Built {
  processor: MessageProcessor<ComponentApi> | null;
  surface: SurfaceModel<never> | null;
  error: string | null;
}

/** Construit la surface `surfaceId` à partir de `messages` ; n'émet rien, ne lève rien. */
export function buildSurface(
  messages: A2uiMessage[],
  surfaceId: string,
  onAction: (action: A2uiClientAction) => void,
): Built {
  if (messages.length === 0) return { processor: null, surface: null, error: null };
  const processor = new MessageProcessor([catalog], onAction);
  const get = () => (processor.model.surfacesMap.get(surfaceId) as SurfaceModel<never> | undefined) ?? null;
  try {
    processor.processMessages(messages);
  } catch (e) {
    // Une surface a pu être créée avant l'erreur : elle ne doit pas fuir.
    get()?.dispose();
    return { processor: null, surface: null, error: String(e) };
  }
  return { processor, surface: get(), error: null };
}

/** La surface vivante : son processeur, la surface construite et les messages déjà traités. */
interface Live {
  surfaceId: string;
  processor: MessageProcessor<ComponentApi>;
  surface: SurfaceModel<never> | null;
  done: A2uiMessage[];
}

/**
 * `next` prolonge-t-elle `done` ? Les réducteurs (`surfacesReducer`) n'ajoutent qu'en fin
 * en gardant les mêmes objets : comparer les bornes suffit (temps constant).
 */
const prolongs = (done: A2uiMessage[], next: A2uiMessage[]) =>
  done.length > 0 && next.length > done.length && next[0] === done[0] && next[done.length - 1] === done[done.length - 1];

export function SurfaceView({ messages, surfaceId, onAction, onError }: { /* inchangé */ }) {
  const handlers = useRef({ onAction, onError });
  handlers.current = { onAction, onError };
  const [surface, setSurface] = useState<SurfaceModel<never> | null>(null);
  const live = useRef<Live | null>(null);
  useEffect(() => {
    const current = live.current;
    if (current && current.surfaceId === surfaceId && prolongs(current.done, messages)) {
      try {
        current.processor.processMessages(messages.slice(current.done.length));
      } catch (e) {
        // Refusé : signalé une fois. La validation précède toute modification du modèle :
        // la surface affichée reste valide, et la suite refusée n'est pas rejouée.
        handlers.current.onError(String(e));
      }
      current.done = messages;
      // La suite a pu créer la surface (première liste sans `createSurface` pour cet identifiant).
      const now = (current.processor.model.surfacesMap.get(surfaceId) as SurfaceModel<never> | undefined) ?? null;
      if (now !== current.surface) {
        current.surface = now;
        setSurface(now);
      }
      return;
    }
    current?.surface?.dispose();
    live.current = null;
    const built = buildSurface(messages, surfaceId, (action) => handlers.current.onAction(action));
    if (built.error) handlers.current.onError(built.error);
    if (built.processor) live.current = { surfaceId, processor: built.processor, surface: built.surface, done: messages };
    setSurface(built.surface);
  }, [messages, surfaceId]);
  // Démontage (et premier démontage de StrictMode) : libère la surface ; un remontage la reconstruit.
  useEffect(
    () => () => {
      live.current?.surface?.dispose();
      live.current = null;
    },
    [],
  );
  return surface ? <div className="a2ui-surface"><A2uiSurface surface={surface} /></div> : null;
}
```

```rust
fn is_hidden_control(c: char) -> bool {
    matches!(c, '\u{200B}'..='\u{200F}' | '\u{202A}'..='\u{202E}' | '\u{2060}'..='\u{2064}' | '\u{2066}'..='\u{2069}' | '\u{FEFF}')
}

/// Refuse un texte de l'agent trop long (`max` caractères) ou contenant un contrôle invisible.
pub fn check_text(what: &str, text: &str, max: usize) -> Result<()> {
    let n = text.chars().count();
    ensure!(n <= max, AgentFormSnafu { reason: format!("{what}: {n} characters, at most {max}") });
    ensure!(
        !text.chars().any(is_hidden_control),
        AgentFormSnafu { reason: format!("{what}: invisible or bidirectional control characters are not allowed") }
    );
    Ok(())
}

/// Refuse une couleur qui n'est pas `#rgb`, `#rgba`, `#rrggbb` ou `#rrggbbaa`.
pub fn check_hex(what: &str, color: &str) -> Result<()> {
    let hex = color.strip_prefix('#').unwrap_or_default();
    ensure!(
        matches!(hex.len(), 3 | 4 | 6 | 8) && hex.chars().all(|c| c.is_ascii_hexdigit()),
        AgentFormSnafu { reason: format!("{what}: {color} is not a hex color") }
    );
    Ok(())
}
```

```rust
//! La surface d'un tour de l'agent : consigne, timeline repliable, note en
//! cours et issue. Constructeurs purs ; le réducteur des tours
//! (`oku-slides-agent::turns`) tient l'état et émet par le hub.

use oku_slides_a2ui::{Component, ComponentKind, Dynamic, ServerMessage, TextVariant, TimelineStep};
use oku_slides_i18n::Localizer;
use serde_json::{Value, json};

use super::bounds::NOTE_CHARS;
use super::forms::{Place, Surface, surface};

/// Où en est un tour.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum TurnState {
    /// L'agent travaille.
    Running,
    /// Fini normalement (`end_turn`), en `secs` secondes.
    Done { secs: u64 },
    /// Fin autre que `end_turn` (`cancelled`, `max_tokens`, `interrupted`…).
    Stopped { stop: String, secs: u64 },
    /// Erreur (démarrage, connexion, agent arrêté) : `message` est déjà traduit.
    Failed { message: String, secs: u64 },
}

/// Ce que la surface d'un tour montre.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TurnView {
    /// Numéro du tour (donné par `SurfaceHub::begin_turn`).
    pub n: u32,
    /// La consigne de l'utilisateur.
    pub prompt: String,
    /// Entrées du plan ACP, affichées avant les étapes.
    pub plan: Vec<TimelineStep>,
    /// Étapes : outils groupés et notes de l'agent, dans l'ordre.
    pub steps: Vec<TimelineStep>,
    /// Nombre d'appels d'outils du tour.
    pub tools: u32,
    /// Nombre de notes de l'agent devenues étapes.
    pub notes: u32,
    /// Texte de l'agent depuis la dernière étape (affiché en note pendant le tour).
    pub narration: String,
    /// Où en est le tour.
    pub state: TurnState,
}

/// Identifiant de la surface du tour `n`.
pub fn turn_id(n: u32) -> String {
    format!("turn-{n}")
}

/// Première ligne non vide de `text`, coupée à `max` caractères (« … » compris).
pub fn first_line(text: &str, max: usize) -> String {
    if max == 0 {
        return String::new();
    }
    let line = text.lines().map(str::trim).find(|l| !l.is_empty()).unwrap_or_default();
    if line.chars().count() <= max {
        return line.to_owned();
    }
    let mut cut: String = line.chars().take(max.saturating_sub(1)).collect();
    cut.push('…');
    cut
}

fn outcome(state: &TurnState, l: &Localizer) -> String {
    match state {
        TurnState::Running | TurnState::Done { .. } => String::new(),
        TurnState::Stopped { stop, .. } => match stop.as_str() {
            "cancelled" => l.tr("agent-turn-stopped"),
            "max_tokens" => l.tr("agent-turn-max-tokens"),
            "max_turn_requests" => l.tr("agent-turn-max-turns"),
            "refusal" => l.tr("agent-turn-refusal"),
            "interrupted" => l.tr("agent-turn-interrupted"),
            other => l.tr_with("agent-turn-ended", &[("stop", other.into())]),
        },
        TurnState::Failed { message, .. } => message.clone(),
    }
}

/// Le modèle de données de la surface du tour.
pub fn turn_data(v: &TurnView, l: &Localizer) -> Value {
    let secs = match &v.state {
        TurnState::Done { secs } | TurnState::Stopped { secs, .. } | TurnState::Failed { secs, .. } => *secs,
        TurnState::Running => 0,
    };
    let running = v.state == TurnState::Running;
    let mut parts = vec![l.tr_with("agent-turn-tools", &[("tools", v.tools.into())])];
    if v.notes > 0 {
        parts.push(l.tr_with("agent-turn-notes", &[("notes", v.notes.into())]));
    }
    parts.push(l.tr_with("agent-turn-secs", &[("secs", secs.into())]));
    let summary = parts.join(" · ");
    let steps: Vec<&TimelineStep> = v.plan.iter().chain(&v.steps).collect();
    json!({
        "steps": steps,
        "collapsed": !running,
        "summary": summary,
        "narration": if running { first_line(&v.narration, NOTE_CHARS) } else { String::new() },
        "outcome": outcome(&v.state, l),
    })
}

/// La surface complète du tour (à son ouverture, ou pour une resynchronisation).
pub fn turn_surface(v: &TurnView, l: &Localizer) -> Surface {
    let id = turn_id(v.n);
    let components = vec![
        Component::column("root", &["prompt", "timeline", "narration", "outcome"]),
        Component::new("prompt", ComponentKind::Prompt { text: Dynamic::Literal(v.prompt.clone()) }),
        Component::new(
            "timeline",
            ComponentKind::Timeline {
                steps: Dynamic::path("/steps"),
                collapsed: Dynamic::path("/collapsed"),
                summary: Dynamic::path("/summary"),
            },
        ),
        Component::new("narration", ComponentKind::Text { text: Dynamic::path("/narration"), variant: Some(TextVariant::Note) }),
        Component::new("outcome", ComponentKind::Text { text: Dynamic::path("/outcome"), variant: Some(TextVariant::Note) }),
    ];
    let mut s = surface(&id, Place::Thread, None, components, turn_data(v, l));
    s.turn = Some(v.n);
    s.live = false;
    s
}

/// Les écritures qui font passer la surface du tour `n` de `sent` à `data` : une par clé
/// racine qui a changé (`/narration` seule pendant que l'agent écrit, pas tout le modèle).
pub fn turn_patches(n: u32, sent: &Value, data: &Value) -> Vec<ServerMessage> {
    let Value::Object(next) = data else { return vec![ServerMessage::set_data_model(turn_id(n), data.clone())] };
    next.iter()
        .filter(|(k, v)| sent.get(k.as_str()) != Some(*v))
        .map(|(k, v)| ServerMessage::update_data_model(turn_id(n), &format!("/{k}"), v.clone()))
        .collect()
}
```

```rust
    pub fn has_actions(&self) -> bool {
        self.messages.iter().any(|m| match &m.body {
            ServerBody::UpdateComponents(u) => u.components.iter().any(|c| !c.kind.actions().is_empty()),

    /// La même surface, en lecture seule : champs sans action, boutons retirés (et retirés
    /// de leurs parents ; un parent à enfant unique dont l'enfant disparaît disparaît aussi).
    pub fn without_actions(&self) -> Surface {
        let mut s = self.clone();
        for m in &mut s.messages {
            let ServerBody::UpdateComponents(u) = &mut m.body else { continue };
            let mut removed: Vec<String> = Vec::new();
            let mut kept = Vec::with_capacity(u.components.len());
            for c in std::mem::take(&mut u.components) {
                match c.kind.without_action() {
                    Some(kind) => kept.push(Component { id: c.id, kind }),
                    None => removed.push(c.id),
                }
            }
            // La racine ne disparaît jamais : un bouton racine devient une colonne vide.
            if removed.iter().any(|id| id == "root") {
                removed.retain(|id| id != "root");
                kept.push(Component::column("root", &[]));
            }
            // Jusqu'à stabilité : retirer un bouton peut vider une carte, qui disparaît à son tour.
            loop {
                let before = removed.len();
                kept.retain_mut(|c| match &mut c.kind {
                    ComponentKind::Column { children } | ComponentKind::Row { children } => {
                        children.retain(|id| !removed.contains(id));
                        true
                    }
                    ComponentKind::Card { child, .. } | ComponentKind::Disclosure { child, .. } if removed.contains(child) => {
                        if c.id == "root" {
                            // La racine reste : elle devient une colonne vide.
                            c.kind = ComponentKind::Column { children: Vec::new() };
                            return true;
                        }
                        removed.push(c.id.clone());
                        false
                    }
                    _ => true,
                });
                if removed.len() == before {
                    break;
                }
            }
            u.components = kept;
        }
        s
    }
```

```rust
        let n = {
            let mut state = self.state();
            state.turns = state.turns.saturating_add(1);
            let n = state.turns;
            state.turn = Some(n);
            state.live_turns.insert(n);
            n
        };
        self.expire_actions();
        n
    }

    /// Range `surface` dans le tour en cours si elle est du fil et n'en a pas (verrou déjà pris).
    pub(super) fn tag_in(state: &HubState, surface: &mut Surface) {
        if surface.place == Place::Thread && surface.turn.is_none() {
            surface.turn = state.turn;
        }
    }

    /// Une surface figée (composition `render`, question répondue) dans son tour.
    ///
    /// Refusée (`false`) si l'onglet est fermé, si aucun tour n'est ouvert, ou si son tour a
    /// quitté le fil : la décision et l'insertion se font sous le même verrou.
    pub fn show_static(&self, mut surface: Surface) -> bool {
        let oldest = {
            let mut state = self.state();
            Self::tag_in(&state, &mut surface);
            let Some(turn) = surface.turn else { return false };
            if state.closed || !state.live_turns.contains(&turn) {
                return false;
            }
            surface.live = false;
            let plain = surface.has_actions().then(|| surface.without_actions());
            state.shows.insert(surface.id.clone(), Shown::Static { turn: Some(turn), plain, expired: false, report: false });
            // Au plus `STATIC_PER_TURN` surfaces figées par tour : la plus ancienne cède la place.
            let same: Vec<String> = state
                .open
                .iter()
                .filter(|s| s.turn == Some(turn) && s.id != surface.id && !s.live)
                // Le reçu du tour ne compte pas : il est unique et ne doit jamais céder sa place.
                .filter(|s| matches!(state.shows.get(&s.id), Some(Shown::Static { report: false, .. })))
                .map(|s| s.id.clone())
                .collect();
            let excess = (same.len() + 1).saturating_sub(STATIC_PER_TURN);
            same.into_iter().take(excess).collect::<Vec<_>>()
        };
        self.close_all(oldest);
        self.emit(McpEvent::Surface { surface });
        true
    }

    /// Fige la surface `id` : elle quitte le dock pour son tour, en lecture seule, avec ses dernières valeurs.
    pub fn freeze(&self, id: &str) {
        let frozen = {
            let mut state = self.state();
            let Some(open) = state.open.iter_mut().find(|s| s.id == id) else {
                tracing::debug!(surface = id, "surface à figer introuvable");
                return;
            };
            // En lecture seule : ses actions n'auraient plus de destinataire.
            let mut frozen = open.without_actions();
            frozen.live = false;
            *open = frozen.clone();
            let turn = frozen.turn;
            state.shows.insert(id.to_owned(), Shown::Static { turn, plain: None, expired: false, report: false });
            frozen
        };
        self.emit(McpEvent::Surface { surface: frozen });
    }

    /// Ferme les surfaces du tour `n` (tour évincé du fil).
    pub fn close_turn(&self, n: u32) {
        let ids = {
            let mut state = self.state();
            state.live_turns.remove(&n);
            Self::thread_ids(&state, |t| t == n)
        };
        self.close_all(ids);
    }

    /// Nouvelle conversation : questions relâchées, plus aucun tour, surfaces du fil fermées.
    ///
    /// Appelée **par l'acteur de l'onglet, avant la consigne suivante** (tâche 7) : jamais
    /// en concurrence avec `begin_turn`. Tout est décidé sous un seul verrou.
    pub fn clear_thread(&self) {
        let ids = {
            let mut state = self.state();
            state.turn = None;
            state.live_turns.clear();
            Self::thread_ids(&state, |_| true)
        };
        // Après l'effacement : une question relâchée ici ne trouve plus son tour et se ferme au lieu de se figer.
        self.cancel_asks();
        self.close_all(ids);
    }

    /// Les surfaces rangées dans un tour que `which` désigne.
    fn thread_ids(state: &HubState, which: impl Fn(u32) -> bool) -> Vec<String> {
        state.open.iter().filter(|s| s.turn.is_some_and(&which)).map(|s| s.id.clone()).collect()
    }

    /// Ferme `ids` (sans verrou tenu par l'appelant).
    pub(super) fn close_all(&self, ids: Vec<String>) {
        for id in ids {
            self.state().shows.remove(&id);
            self.emit(McpEvent::CloseSurface { id });
        }
    }

    /// Les suites des tours passés expirent : leur surface est remplacée par sa version sans actions.
    fn expire_actions(&self) {
        let plains: Vec<Surface> = {
            let mut state = self.state();
            let current = state.turn;
            state
                .shows
                .values_mut()
                .filter_map(|shown| match shown {
                    Shown::Static { turn, plain, expired, .. } if !*expired && *turn != current => {
                        *expired = true;
                        plain.take()
                    }
                    _ => None,
                })
                .collect()
        };
        for surface in plains {
            self.emit(McpEvent::Surface { surface });
        }
    }
}
```

```rust
//! Les tours d'un onglet : chaque évènement de l'agent met à jour la surface
//! de son tour (`turn-N`), émise par le hub comme toute surface. Remplace le
//! fil gardé : l'interface ne reçoit plus que l'état de l'agent.
//!
//! Une mise à jour ne part que pour les clés du modèle qui ont changé (en
//! général `/narration` seule pendant que l'agent écrit). Un tour dont la fin
//! s'est perdue (relais en retard) est clos par le retour de l'agent au repos,
//! ou interrompu par l'ouverture du tour suivant.

use std::collections::{BTreeSet, HashMap, VecDeque};
use std::time::Instant;

use oku_slides_i18n::Localizer;
use oku_slides_session::agent::turn_view::{TurnState, TurnView, first_line, turn_data, turn_id, turn_patches, turn_surface};
use oku_slides_session::agent::{NOTE_CHARS, ServerMessage, StepStatus, Surface, TimelineStep, WHY_MAX};
use serde_json::Value;

use crate::{AgentEvent, AgentState};

/// Tours gardés au plus par onglet ; au-delà, le plus ancien est fermé.
pub(crate) const KEPT_TURNS: usize = 50;
/// Étapes gardées au plus par tour ; au-delà, les outils et notes ne comptent plus que dans le résumé.
pub(crate) const STEPS_MAX: usize = 60;

/// Ce que le relais doit faire après un évènement.
#[derive(Debug)]
pub(crate) enum TurnOut {
    /// Ouvrir (ou remplacer) la surface d'un tour.
    Show(Surface),
    /// Mettre à jour la surface d'un tour (une écriture par clé changée).
    Patch { id: String, messages: Vec<ServerMessage> },
    /// Fermer les surfaces du tour évincé.
    Evict(u32),
    /// Le tour est fini : reçu de repli si l'agent n'en a pas fait.
    Ended { turn: u32, narration: String },
}

#[derive(Debug)]
struct Turn {
    view: TurnView,
    started: Instant,
    /// Chaque outil : l'étape où il est rangé et son dernier statut.
    tools: HashMap<String, (usize, StepStatus)>,
    /// La dernière étape est-elle une étape d'outils ?
    in_tools: bool,
    /// Le dernier texte complet de l'agent (la narration en cours, ou la dernière devenue note).
    last_text: String,
    /// Les données envoyées en dernier : seules les clés qui changent repartent.
    sent: Value,
}

/// Les tours de l'onglet, du plus ancien au plus récent.
#[derive(Debug, Default)]
pub(crate) struct Turns {
    turns: VecDeque<Turn>,
}

fn status(s: &str) -> StepStatus {
    match s {
        "in_progress" => StepStatus::InProgress,
        "completed" => StepStatus::Completed,
        "failed" => StepStatus::Failed,
        _ => StepStatus::Pending,
    }
}

/// Rang d'un statut dans une étape groupée : le plus bas l'emporte (un échec reste visible).
fn rank(st: StepStatus) -> u8 {
    match st {
        StepStatus::Failed => 0,
        StepStatus::InProgress => 1,
        StepStatus::Pending => 2,
        StepStatus::Completed => 3,
    }
}

impl Turn {
    /// Le texte en cours devient une note de la timeline (si la place le permet).
    fn close_narration(&mut self) {
        let text = self.view.narration.trim();
        if !text.is_empty() {
            self.last_text = text.to_owned();
            if self.view.steps.len() < STEPS_MAX {
                let note = first_line(text, NOTE_CHARS);
                self.view.steps.push(TimelineStep { label: note, status: StepStatus::Completed, count: None });
            }
            self.view.notes = self.view.notes.saturating_add(1);
        }
        self.view.narration.clear();
    }

    /// Statut d'une étape d'outils : un échec reste visible, sinon « en cours » tant qu'un outil l'est.
    fn settle_step(&mut self, step: usize) {
        let worst = self.tools.values().filter(|(s, _)| *s == step).map(|(_, st)| *st).min_by_key(|st| rank(*st));
        if let (Some(worst), Some(row)) = (worst, self.view.steps.get_mut(step)) {
            row.status = worst;
        }
    }

    /// Ferme le tour : les outils restés en cours sont soldés selon l'issue ; rend le dernier texte.
    fn finish(&mut self, state: TurnState) -> String {
        let leftover = if matches!(state, TurnState::Done { .. }) { StepStatus::Completed } else { StepStatus::Failed };
        for (_, st) in self.tools.values_mut() {
            if matches!(st, StepStatus::Pending | StepStatus::InProgress) {
                *st = leftover;
            }
        }
        let steps: BTreeSet<usize> = self.tools.values().map(|(s, _)| *s).collect();
        for step in steps {
            self.settle_step(step);
        }
        let narration = self.view.narration.trim();
        let text = if narration.is_empty() { self.last_text.clone() } else { narration.to_owned() };
        self.view.state = state;
        text
    }

    fn secs(&self, now: Instant) -> u64 {
        now.saturating_duration_since(self.started).as_secs()
    }

    /// Les écritures des clés qui ont changé depuis le dernier envoi ; rien si rien n'a changé.
    fn patch(&mut self, l: &Localizer) -> Option<TurnOut> {
        let data = turn_data(&self.view, l);
        let messages = turn_patches(self.view.n, &self.sent, &data);
        self.sent = data;
        (!messages.is_empty()).then(|| TurnOut::Patch { id: turn_id(self.view.n), messages })
    }
}

impl Turns {
    /// Applique `e` ; rend ce que le relais doit émettre.
    pub fn apply(&mut self, e: &AgentEvent, now: Instant, l: &Localizer) -> Vec<TurnOut> {
        match e {
            AgentEvent::UserText { turn, text } => return self.open(*turn, text, now, l),
            // Le hub a déjà été vidé par l'acteur (`clear_thread`, synchrone) : on oublie les tours.
            AgentEvent::Conversation => {
                self.turns.clear();
                return Vec::new();
            }
            _ => {}
        }
        let Some(t) = self.turns.back_mut() else { return Vec::new() };
        if t.view.state != TurnState::Running {
            return Vec::new();
        }
        let mut ended = None;
        match e {
            AgentEvent::Chunk { text } => {
                // Au-delà de `WHY_MAX` caractères, la suite ne s'affiche plus nulle part : on ne la garde pas
                // (un seul morceau trop long est coupé, lui aussi).
                let room = WHY_MAX.saturating_sub(t.view.narration.chars().count());
                t.view.narration.extend(text.chars().take(room));
                // Un morceau vide (`"\n\n"` entre deux outils) ne sépare pas un groupe d'outils.
                if !text.trim().is_empty() {
                    t.in_tools = false;
                }
            }
            AgentEvent::ToolCall { id, title, status: s } => {
                if t.tools.contains_key(id) {
                    // Un même appel annoncé deux fois : traité comme une mise à jour.
                    let step = t.tools[id].0;
                    t.tools.insert(id.clone(), (step, status(s)));
                    t.settle_step(step);
                } else {
                    if !t.in_tools {
                        t.close_narration();
                        if t.view.steps.len() < STEPS_MAX {
                            t.view.steps.push(TimelineStep { label: title.clone(), status: status(s), count: Some(1) });
                        }
                        t.in_tools = true;
                    }
                    t.view.tools = t.view.tools.saturating_add(1);
                    if let Some(step) = t.view.steps.len().checked_sub(1).filter(|_| t.in_tools) {
                        t.tools.insert(id.clone(), (step, status(s)));
                        let count = t.tools.values().filter(|(s, _)| *s == step).count();
                        if let Some(row) = t.view.steps.get_mut(step) {
                            row.label.clone_from(title);
                            row.count = Some(u32::try_from(count).unwrap_or(u32::MAX));
                        }
                        t.settle_step(step);
                    }
                }
            }
            AgentEvent::ToolUpdate { id, title, status: s } => {
                let Some((step, st)) = t.tools.get_mut(id) else { return Vec::new() };
                let step = *step;
                if let Some(s) = s {
                    *st = status(s);
                }
                if let (Some(title), Some(row)) = (title, t.view.steps.get_mut(step)) {
                    row.label.clone_from(title);
                }
                t.settle_step(step);
            }
            AgentEvent::Plan { entries } => {
                t.view.plan = entries
                    .iter()
                    .take(STEPS_MAX)
                    .map(|p| TimelineStep { label: first_line(&p.content, NOTE_CHARS), status: status(&p.status), count: None })
                    .collect();
            }
            AgentEvent::TurnEnded { stop } => {
                let secs = t.secs(now);
                let state = if stop == "end_turn" {
                    TurnState::Done { secs }
                } else {
                    TurnState::Stopped { stop: stop.clone(), secs }
                };
                ended = Some(t.finish(state));
            }
            // L'agent est revenu au repos sans fin de tour (évènement perdu) : le tour est fini.
            AgentEvent::Status { state: AgentState::Idle } => {
                let secs = t.secs(now);
                ended = Some(t.finish(TurnState::Done { secs }));
            }
            AgentEvent::Error { message } => {
                let secs = t.secs(now);
                t.finish(TurnState::Failed { message: message.clone(), secs });
                // Pas de reçu de repli pour un échec, mais le hub doit savoir que le tour est clos.
                ended = Some(String::new());
            }
            AgentEvent::Status { .. } | AgentEvent::UserText { .. } | AgentEvent::Conversation => return Vec::new(),
        }
        let n = t.view.n;
        let mut out: Vec<TurnOut> = t.patch(l).into_iter().collect();
        if let Some(narration) = ended {
            out.push(TurnOut::Ended { turn: n, narration });
        }
        out
    }

    fn open(&mut self, n: u32, prompt: &str, now: Instant, l: &Localizer) -> Vec<TurnOut> {
        let mut out = Vec::new();
        // Un tour précédent resté ouvert (fin perdue) est clos comme interrompu.
        if let Some(prev) = self.turns.back_mut()
            && prev.view.state == TurnState::Running
        {
            let secs = prev.secs(now);
            prev.finish(TurnState::Stopped { stop: "interrupted".into(), secs });
            let k = prev.view.n;
            out.extend(prev.patch(l));
            out.push(TurnOut::Ended { turn: k, narration: String::new() });
        }
        let view = TurnView {
            n,
            prompt: prompt.to_owned(),
            plan: Vec::new(),
            steps: Vec::new(),
            tools: 0,
            notes: 0,
            narration: String::new(),
            state: TurnState::Running,
        };
        let sent = turn_data(&view, l);
        out.push(TurnOut::Show(turn_surface(&view, l)));
        self.turns.push_back(Turn {
            view,
            started: now,
            tools: HashMap::new(),
            in_tools: false,
            last_text: String::new(),
            sent,
        });
        if self.turns.len() > KEPT_TURNS
            && let Some(old) = self.turns.pop_front()
        {
            out.push(TurnOut::Evict(old.view.n));
        }
        out
    }
}
```

```rust
//! Le reçu d'un tour : outil `report`, et reçu de repli quand l'agent n'en
//! a pas fait (sa dernière narration, première phrase en titre).

use oku_slides_a2ui::{Action, Component, ComponentKind, Dynamic};
use oku_slides_i18n::Localizer;
use schemars::JsonSchema;
use serde::Deserialize;
use serde_json::json;
use snafu::OptionExt;

use super::forms::{Place, Surface, lit, surface};
use super::check_len;
use super::bounds::{LABEL_MAX, NOTE_CHARS, PROMPT_MAX, TEXT_MAX, WHY_MAX, check_hex, check_text};
use super::turn_view::first_line;
use crate::error::NoSlideSnafu;
use crate::{Result, Session};

/* `Report`, `NextStep`, `FACTS`, `ACTIONS` : exactement comme dans « Interfaces » ci-dessus. */


/// Le reçu : carte, puis « pourquoi » replié, puis les suites.
pub fn receipt(id: &str, spec: &Report, thumb: Option<&str>, l: &Localizer) -> Surface {
    let mut body = vec!["card".to_owned()];
    let mut components = vec![Component::new(
        "card",
        ComponentKind::Receipt {
            title: Dynamic::Literal(spec.title.clone()),
            facts: spec.facts.clone(),
            thumb: thumb.map(str::to_owned),
            swatch: spec.swatch.clone(),
        },
    )];
    if let Some(why) = spec.why.as_deref().filter(|w| !w.trim().is_empty()) {
        components.push(Component::new(
            "why",
            ComponentKind::Disclosure { summary: Dynamic::Literal(l.tr("agent-report-why")), child: "why-text".into() },
        ));
        components.push(Component::new("why-text", ComponentKind::Markdown { text: Dynamic::Literal(why.to_owned()) }));
        body.push("why".into());
    }
    if !spec.actions.is_empty() {
        let ids: Vec<String> = (0..spec.actions.len()).map(|i| format!("next-{i}")).collect();
        for (bid, a) in ids.iter().zip(&spec.actions) {
            let prompt = a.prompt.clone().unwrap_or_else(|| a.label.clone());
            components.push(Component::button(bid, a.label.clone(), false, Action::event("suggest", [("prompt", lit(json!(prompt)))])));
        }
        let refs: Vec<&str> = ids.iter().map(String::as_str).collect();
        components.push(Component::row("next", &refs));
        body.push("next".into());
    }
    let refs: Vec<&str> = body.iter().map(String::as_str).collect();
    components.insert(0, Component::column("root", &refs));
    let mut s = surface(id, Place::Thread, None, components, json!({}));
    s.live = false;
    s
}

/// Fin (octet) de la première phrase : `.`, `!` ou `?` suivi d'un blanc ou de la fin, ou un saut de ligne.
/// « 4.5 », « v0.9 » ne coupent pas ; les délimiteurs étant ASCII, la coupe tombe sur une frontière de caractère.
fn sentence_end(text: &str) -> usize {
    let bytes = text.as_bytes();
    for (i, b) in bytes.iter().enumerate() {
        match b {
            b'\n' => return i,
            b'.' | b'!' | b'?' if bytes.get(i + 1).is_none_or(|n| n.is_ascii_whitespace()) => return i + 1,
            _ => {}
        }
    }
    text.len()
}

/// Reçu de repli : la première phrase de `narration` en titre, le reste replié.
pub fn fallback(id: &str, narration: &str, l: &Localizer) -> Option<Surface> {
    let text = narration.trim();
    if text.is_empty() {
        return None;
    }
    let end = sentence_end(text);
    let first = text[..end].trim();
    let title = first_line(first, NOTE_CHARS);
    // Un titre coupé ne perd rien : la phrase entière reste dans l'explication.
    let rest = if title == first { text[end..].trim() } else { text };
    let spec = Report {
        title,
        facts: Vec::new(),
        slide: None,
        swatch: None,
        // Borné comme un `why` d'agent : une narration très longue ne devient pas une carte démesurée.
        why: (!rest.is_empty()).then(|| rest.chars().take(WHY_MAX).collect()),
        actions: Vec::new(),
    };
    Some(receipt(id, &spec, None, l))
}

impl Session {
    /// Surface `report` : bornes vérifiées, miniature de la slide rendue.
    pub fn report_surface(&mut self, id: &str, spec: &Report) -> Result<ReceiptSurfaces> {
        check_len("facts", spec.facts.len(), FACTS)?;
        check_len("actions", spec.actions.len(), ACTIONS)?;
        check_text("title", &spec.title, TEXT_MAX)?;
        for (i, f) in spec.facts.iter().enumerate() {
            check_text(&format!("facts[{i}]"), f, TEXT_MAX)?;
        }
        if let Some(why) = &spec.why {
            check_text("why", why, WHY_MAX)?;
        }
        for (i, a) in spec.actions.iter().enumerate() {
            check_text(&format!("actions[{i}].label"), &a.label, LABEL_MAX)?;
            if let Some(p) = &a.prompt {
                check_text(&format!("actions[{i}].prompt"), p, PROMPT_MAX)?;
            }
        }
        if let Some(c) = &spec.swatch {
```

```rust
    ///
    /// Refusé (`false`) comme `show_static` : onglet fermé, aucun tour ouvert, ou tour sorti du fil.
    pub fn show_report(&self, report: ReceiptSurfaces) -> bool {
        let ReceiptSurfaces { mut surface, plain } = report;
        let old: Vec<String> = {
            let mut state = self.state();
            Self::tag_in(&state, &mut surface);
            let Some(turn) = surface.turn else { return false };
            if state.closed || !state.live_turns.contains(&turn) {
                return false;
            }
            surface.live = false;
            let old: Vec<String> = state
                .shows
                .iter()
                .filter(|(_, s)| matches!(s, Shown::Static { turn: t, report: true, .. } if *t == Some(turn)))
                .map(|(id, _)| id.clone())
                .collect();
            for id in &old {
                state.shows.remove(id);
            }
            state.reported.insert(turn);
            let plain = plain.map(|mut p| {
                p.turn = Some(turn);
                p.live = false;
                p
            });
            state.shows.insert(surface.id.clone(), Shown::Static { turn: Some(turn), plain, expired: false, report: true });
            old
        };
        for id in old {
            self.emit(McpEvent::CloseSurface { id });
        }
        self.emit(McpEvent::Surface { surface });
        true
    }

    /// Le tour `turn` a-t-il son reçu ?
    pub fn has_report(&self, turn: u32) -> bool {
        self.state().reported.contains(&turn)
    }

    /// Fin du tour `turn` : plus de tour en cours, et reçu de repli si l'agent n'en a pas fait.
    pub fn end_turn(&self, turn: u32, narration: &str) {
        {
            // Une surface qui arriverait encore (outil tardif d'un tour annulé) n'est rangée dans aucun tour : refusée.
            let mut state = self.state();
            if state.turn == Some(turn) {
                state.turn = None;
            }
        }
        if self.has_report(turn) || narration.trim().is_empty() {
            return;
        }
        let id = self.next_id("report");
        if let Some(mut s) = oku_slides_session::agent::receipt::fallback(&id, narration, &self.localizer) {
            s.turn = Some(turn);
            self.show_report(ReceiptSurfaces { surface: s, plain: None });
        }
    }
```

```rust
//! `render` : une composition libre du catalogue v3 par l'agent, validée
//! ici. Une erreur revient à l'agent (`AgentForm`), lisible, pour qu'il corrige.

use std::collections::{HashMap, HashSet};

use oku_slides_a2ui::{Component, ComponentKind, Dynamic, Tone};
use schemars::JsonSchema;
use serde::Deserialize;
use serde_json::{Value, json};
use snafu::ensure;

use super::bounds::{LABEL_MAX, TEXT_MAX, WHY_MAX, check_text};
use super::forms::{Place, Surface, surface};
use crate::Result;
use crate::error::AgentFormSnafu;

/* `Render`, `RENDER_MAX`, `RENDER_DEPTH`, `RENDER_BYTES` : exactement comme dans « Interfaces » ci-dessus. */

/// Refus lisible par l'agent.
fn refuse<T>(reason: String) -> Result<T> {
    Err(AgentFormSnafu { reason }.build().into())
}

/// Une clé de `given` absente de `known`, en ignorant les `null` explicites
/// (une propriété facultative écrite `null` n'est pas inconnue).
fn unknown_key<'a>(given: &'a Value, known: &Value) -> Option<&'a String> {
    let (Value::Object(given), Value::Object(known)) = (given, known) else { return None };
    given.iter().find(|(k, v)| !v.is_null() && !known.contains_key(*k)).map(|(k, _)| k)
}

/// Un objet `{"path": …}` quelque part dans `v` : une liaison au modèle de données.
fn has_path(v: &Value) -> bool {
    match v {
        Value::Object(map) => (map.len() == 1 && map.contains_key("path")) || map.values().any(has_path),
        Value::Array(items) => items.iter().any(has_path),
        _ => false,
    }
}

/// Les styles réservés à l'hôte : un agent ne peut pas imiter une demande de permission.
fn check_host_styles(i: usize, c: &Component) -> Result<()> {
    let reserved = matches!(
        &c.kind,
        ComponentKind::Button { primary: Some(true), .. }
            | ComponentKind::Button { danger: Some(true), .. }
            | ComponentKind::Card { tone: Some(Tone::Danger), .. }
            | ComponentKind::Badge { tone: Some(Tone::Danger), .. }
    );
    ensure!(!reserved, AgentFormSnafu { reason: format!("components[{i}]: primary/danger styles are reserved to Oku Slides") });
    Ok(())
}

/// Les longueurs de chaque texte visible (toutes les valeurs sont littérales, voir `has_path`).
fn check_content(i: usize, c: &Component) -> Result<()> {
    let at = |what: &str| format!("components[{i}].{what}");
    let lit = |d: &Dynamic<String>| match d {
        Dynamic::Literal(s) => s.clone(),
        Dynamic::Path { .. } => String::new(),
    };
    match &c.kind {
        ComponentKind::Text { text, .. } | ComponentKind::Markdown { text } => check_text(&at("text"), &lit(text), WHY_MAX),
        ComponentKind::Badge { text, .. } => check_text(&at("text"), &lit(text), TEXT_MAX),
        ComponentKind::Disclosure { summary, .. } => check_text(&at("summary"), &lit(summary), TEXT_MAX),
        ComponentKind::Button { label, .. } => check_text(&at("label"), &lit(label), LABEL_MAX),
        ComponentKind::TextField { label, .. }
        | ComponentKind::Stepper { label, .. }
        | ComponentKind::Slider { label, .. }
        | ComponentKind::ColorField { label, .. }
        | ComponentKind::Select { label, .. } => check_text(&at("label"), &lit(label), TEXT_MAX),
        ComponentKind::DiffText { segments } => {
            let all: String = segments.iter().map(|s| s.text.as_str()).collect();
            check_text(&at("segments"), &all, WHY_MAX)
        }
        _ => Ok(()),
    }
}

fn parse(i: usize, v: &Value) -> Result<Component> {
    ensure!(!has_path(v), AgentFormSnafu { reason: format!("components[{i}]: values must be literal (no {{path}} bindings)") });
    let c: Component = match serde_json::from_value(v.clone()) {
        Ok(c) => c,
        Err(e) => return refuse(format!("components[{i}]: {e}")),
    };
    let back = serde_json::to_value(&c).unwrap_or(Value::Null);
    if let Some(extra) = unknown_key(v, &back) {
        return refuse(format!("components[{i}]: unknown property {extra:?}"));
    }
    if !c.agent_allowed() {
        let name = back.get("component").and_then(Value::as_str).unwrap_or_default();
        return refuse(format!("components[{i}]: {name} is reserved to Oku Slides"));
    }
    check_host_styles(i, &c)?;
    for a in c.kind.actions() {
        let ComponentKind::Button { label: Dynamic::Literal(label), .. } = &c.kind else {
            return refuse(format!("components[{i}]: only buttons may carry an action"));
        };
        let prompt = match a.event.context.get("prompt") {
            Some(Dynamic::Literal(Value::String(p))) if a.event.context.len() == 1 && a.event.name == "suggest" => p,
            _ => return refuse(format!("components[{i}]: only suggest actions with a literal prompt are allowed")),
        };
        // Ce que l'on voit est ce qui part : le bouton porte exactement la consigne qu'il envoie.
        ensure!(label == prompt, AgentFormSnafu { reason: format!("components[{i}]: a suggest button must send its own label as prompt") });
    }
    check_content(i, &c)?;
    Ok(c)
}

/// Vérifie que les composants forment un arbre enraciné en `root` : chaque
/// composant a au plus un parent et n'est visité qu'une fois (pas de partage,
/// pas de cycle), la profondeur est bornée, aucun composant n'est orphelin.
/// Parcours itératif en largeur : au plus `components.len()` visites, quelle
/// que soit la longueur des listes `children` (pas d'explosion combinatoire).
fn check_tree(components: &[Component]) -> Result<()> {
    let mut by_id: HashMap<&str, &Component> = HashMap::with_capacity(components.len());
    for c in components {
        if by_id.insert(c.id.as_str(), c).is_some() {
            return refuse(format!("duplicate component id {:?}", c.id));
        }
    }
    ensure!(by_id.contains_key("root"), AgentFormSnafu { reason: "no component with id \"root\"".to_owned() });
    let mut seen: HashSet<&str> = HashSet::with_capacity(components.len());
    let mut level: Vec<&str> = vec!["root"];
    let mut depth = 0;
    while !level.is_empty() {
        depth += 1;
        ensure!(depth <= RENDER_DEPTH, AgentFormSnafu { reason: format!("deeper than {RENDER_DEPTH} levels") });
        let mut next = Vec::new();
        for id in level {
            if !seen.insert(id) {
                return refuse(format!("component {id:?} is used more than once (the components must form a tree)"));
            }
            let Some(c) = by_id.get(id) else { return refuse(format!("unknown child {id:?}")) };
            next.extend(c.kind.children());
        }
        level = next;
    }
    if let Some(orphan) = components.iter().find(|c| !seen.contains(c.id.as_str())) {
        return refuse(format!("component {:?} is not reachable from \"root\"", orphan.id));
    }
    Ok(())
}

/// La surface d'une composition libre, ou pourquoi elle est refusée.
pub fn render(id: &str, spec: &Render) -> Result<Surface> {
    // Le nombre d'abord : on ne sérialise pas une liste démesurée pour la mesurer.
    ensure!(spec.components.len() <= RENDER_MAX, AgentFormSnafu { reason: format!("at most {RENDER_MAX} components") });
    let bytes = serde_json::to_vec(spec.components.as_slice()).map_or(usize::MAX, |b| b.len());
    ensure!(bytes <= RENDER_BYTES, AgentFormSnafu { reason: format!("at most {RENDER_BYTES} bytes of components") });
    let components: Vec<Component> =
        spec.components.iter().enumerate().map(|(i, v)| parse(i, v)).collect::<Result<_>>()?;
    check_tree(&components)?;
    let mut s = surface(id, Place::Thread, None, components, json!({}));
    s.live = false;
    Ok(s)
}
```

```ts
/** Où s'affichent les surfaces ouvertes ; aucune n'est jamais invisible. */
export interface Routed {
  /** Fiche posée sous son élément, sur la scène. */
  stage?: Surface;
  /** Tiroir des variantes (le plus récent : l'hôte n'en garde qu'un). */
  drawer?: Surface;
  /** Fenêtre de confirmation (la plus ancienne : une question en attente n'est jamais remplacée sous le curseur). */
  modal?: Surface;
  /** Surfaces vivantes du fil : réglages d'abord, la question en dernier (au plus près du micro). */
  dock: Surface[];
  /** Les tours, du plus ancien au plus récent : la surface du tour puis ses surfaces figées. */
  turns: { turn: number; surfaces: Surface[] }[];
  /** Fiches dont l'élément n'est pas à l'écran, et surfaces figées du fil sans tour. */
  loose: Surface[];
}

// `isQuestion` et `isAsking` existent depuis la tâche 6.

/**
 * Répartit les surfaces. `shown` : la slide affichée et ses cibles (`null`
 * pendant un changement de slide) ; une fiche n'y va que si son élément y est.
 * Au dock, les réglages d'abord et la question en dernier, au plus près du micro.
 */
export function routeSurfaces(list: Surface[], shown: { slide: string; targets: string[] } | null): Routed {
  const sheets = byPlace(list, "sheet");
  const stage = sheets.find((s) => !!shown && s.anchor?.slide === shown.slide && shown.targets.includes(s.anchor.element));
  const thread = byPlace(list, "thread");
  const dock = thread.filter((s) => s.live).sort((a, b) => Number(isQuestion(a)) - Number(isQuestion(b)));
  const byTurn = new Map<number, Surface[]>();
  for (const s of thread) {
    if (s.live || s.turn === undefined) continue;
    const group = byTurn.get(s.turn);
    if (group) group.push(s);
    else byTurn.set(s.turn, [s]);
  }
  const turns = [...byTurn.entries()]
    .sort(([a], [b]) => a - b)
    .map(([turn, surfaces]) => ({ turn, surfaces: [...surfaces].sort((a, b) => Number(b.id === `turn-${turn}`) - Number(a.id === `turn-${turn}`)) }));
  return {
    stage,
    drawer: byPlace(list, "drawer").at(-1),
    modal: byPlace(list, "modal")[0],
    dock,
    turns,
    // Fiches hors de la scène, et surfaces figées du fil sans tour (aucune n'est jamais invisible).
    loose: [...sheets.filter((s) => s !== stage), ...thread.filter((s) => !s.live && s.turn === undefined)],
  };
}
```

```tsx
// Le dock : les surfaces vivantes du fil (question en attente, réglages), au-dessus du micro.

import type { ReactNode } from "react";
import { useState } from "react";
import { Toggle } from "../a2ui/Toggle";
import type { Surface } from "../api";
import { t } from "../i18n";
import { isQuestion } from "./surfaces";

/**
 * Les surfaces vivantes ; rien (0 px) sans elles. Quand une question attend,
 * les réglages se replient sur une ligne qui les rouvre : la question reste à l'écran.
 * Ce choix vaut pour une question : la suivante les replie à nouveau.
 */
export function AgentDock({ surfaces, view }: { surfaces: Surface[]; view: (s: Surface) => ReactNode }) {
  const question = surfaces.find(isQuestion)?.id ?? null;
  // L'ouverture des réglages est mémorisée pour une question donnée.
  const [openFor, setOpenFor] = useState<string | null>(null);
  if (surfaces.length === 0) return null;
  const open = openFor !== null && openFor === question;
  return (
    <section className="agent-dock agent-keys" aria-label={t("ui-agent-dock")} aria-live="polite">
      {surfaces.map((s) => {
        const settings = question !== null && !isQuestion(s);
        const folded = settings && !open;
        return (
          <div key={s.id} className={`agent-dock-item${isQuestion(s) ? " ask" : ""}`} data-surface-id={s.id}>
            {settings && (
              <Toggle open={!folded} onToggle={() => setOpenFor(open ? null : question)} className="a2ui-hint">
                {t("ui-agent-dock-settings")}
              </Toggle>
            )}
            {!folded && view(s)}
          </div>
        );
      })}
    </section>
  );
}
```

```tsx
// Le fil de l'agent : ses tours (surfaces A2UI de l'hôte) et le dock des surfaces vivantes.

import type { A2uiClientAction } from "@a2ui/web_core/v0_9";
import { lazy, Suspense, useCallback, useEffect, useRef, useState } from "react";
import type { AgentState, Surface } from "../api";
import { t } from "../i18n";
import { Icon } from "../icons";
import { AgentDock } from "./AgentDock";
import type { Routed } from "./surfaces";

const SurfaceView = lazy(() => import("../a2ui/SurfaceView").then((m) => ({ default: m.SurfaceView })));

/** Clés écrites en entier : `i18n-keys.test.ts` cherche chaque clé en littéral. */
const STATE_KEY: Record<AgentState, string> = {
  idle: "ui-agent-state-idle",
  starting: "ui-agent-state-starting",
  working: "ui-agent-state-working",
};

/** Le fil et son dock ; rien tant qu'il n'y a ni tour ni surface. */
export function AgentThread({ state, turns, loose, dock, onAction, onNewConversation, onError }: {
  state: AgentState;
  onAction: (surface: Surface, action: A2uiClientAction) => void;
  onNewConversation: () => void;
  onError: (message: string) => void;
} & Pick<Routed, "turns" | "loose" | "dock">) {
  const scroller = useRef<HTMLDivElement>(null);
  const observer = useRef<ResizeObserver | null>(null);
  const [pinned, setPinned] = useState(true);
  const pinnedRef = useRef(pinned);
  pinnedRef.current = pinned;
  const lastTurn = turns.at(-1)?.turn;
  const toBottom = () => {
    const el = scroller.current;
    if (el) el.scrollTop = el.scrollHeight;
  };
  // Un nouveau tour se suit à nouveau, même si l'utilisateur était remonté (la référence d'abord :
  // l'observateur ci-dessous la lit avant le prochain rendu).
  useEffect(() => {
    pinnedRef.current = true;
    setPinned(true);
    toBottom();
  }, [lastTurn]);
  // Le contenu A2UI grandit sans re-rendre ce composant (signaux internes) : on observe la taille
  // de la liste entière. Ref de rappel : la liste n'existe pas tant que le fil est vide (le composant
  // rend `null`), un effet sans dépendances ne la verrait jamais.
  const list = useCallback((el: HTMLOListElement | null) => {
    observer.current?.disconnect();
    observer.current = null;
    if (!el || typeof ResizeObserver === "undefined") return;
    const watch = new ResizeObserver(() => {
      if (pinnedRef.current) toBottom();
    });
    watch.observe(el);
    observer.current = watch;
  }, []);
  if (turns.length === 0 && loose.length === 0 && dock.length === 0) return null;
  const view = (s: Surface) => (
    <Suspense fallback={null}>
      <SurfaceView surfaceId={s.id} messages={s.messages} onAction={(a) => onAction(s, a)} onError={onError} />
    </Suspense>
  );
  return (
    <section className="agent-thread" aria-label={t("ui-agent-thread")}>
      <header className="agent-thread-head">
        <span className="caption">{t(STATE_KEY[state])}</span>
        <button type="button" className="token ghost agent-new" aria-label={t("ui-agent-new-conversation")} title={t("ui-agent-new-conversation")} onClick={onNewConversation}>{Icon.newChat}</button>
      </header>
      <div
        ref={scroller}
        className="agent-scroller"
        onScroll={(e) => {
          const el = e.currentTarget;
          setPinned(el.scrollHeight - el.scrollTop - el.clientHeight < 24);
        }}
      >
        <ol ref={list} className="agent-turns">
          {turns.map(({ turn, surfaces }) => (
            // Seul le dernier tour est annoncé : les anciens ne changent plus.
            <li key={turn} className="agent-turn" aria-live={turn === lastTurn ? "polite" : undefined}>
              {surfaces.map((s) => <div key={s.id} data-surface-id={s.id}>{view(s)}</div>)}
            </li>
          ))}
          {loose.map((s) => <li key={s.id} className="agent-turn" data-surface-id={s.id}>{view(s)}</li>)}
        </ol>
      </div>
      {!pinned && state === "working" && (
        <button
          type="button"
          className="token agent-jump"
          onClick={() => {
            pinnedRef.current = true;
            setPinned(true);
            toBottom();
          }}
        >
          {t("ui-agent-jump")}
        </button>
      )}
      <AgentDock surfaces={dock} view={view} />
    </section>
  );
}
```
